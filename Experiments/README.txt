R PROGRAMMING - 21 EXPERIMENTS WITH INPUTS AND DATASETS

This ZIP contains 21 separate R script files. Each file includes:
- Experiment title
- An INPUTS / INPUT DATASET comment section
- Input values or dataset setup inside the R code
- Program statements and output commands

No external dataset downloads are required.

Built-in R datasets used:
- women (Experiment 5)
- airquality (Experiment 12)
- ChickWeight (Experiments 14 and 20)
- iris (Experiments 15 and 21)
- USArrests (Experiment 16)
- Titanic (Experiment 17)

Other data:
- Experiment 10 creates exam_data directly and saves exam_data.csv.
- Experiment 11 creates a sample CSV if exam_data.csv is absent, then reads it.
- Experiment 19 creates an illustrative advertising dataset inside the script.
- Experiment 17's built-in Titanic dataset has no individual passenger ages.
  Its age histogram uses illustrative sample ages, clearly labeled as such.

Packages:
- reshape2 is automatically checked/installed in Experiments 12 and 14.
- nnet is automatically checked/installed in Experiment 21.
The first installation may require an internet connection.

To run:
1. Extract the ZIP.
2. Open a numbered .R file in RStudio.
3. Run the script.
